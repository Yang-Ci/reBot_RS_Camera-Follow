# B601 本地监视页面

启动：`python3 web/server.py`，打开 <http://127.0.0.1:8765>。不需要启动机械臂即可查看页面。模型资源默认读取 `/home/robot/ReBot_Arm_DigitalTwin_RS/reBotArm_simulator-RS`；迁移后设置 `REBOT_TWIN_PATH` 指向数字孪生项目的 `reBotArm_simulator-RS` 目录。页面使用数字孪生项目的 B601 URDF；腕部相机本体使用 Orbbec 官方 Gemini 335/336 网格和本仓库 `models/wrist_camera/gemini336.urdf`。支架使用 Seeed 的 D435/Gemini 2 V1 模型；底座和相机依据 CAD 安装面作名义对齐，光学位姿尚待实机验证，见 [模型说明](../models/wrist_camera/README.md)。

数字孪生资源来自 [Yang-Ci / ReBot_Arm_DigitalTwin_RS](https://github.com/Yang-Ci/ReBot_Arm_DigitalTwin_RS)。电脑摄像头模拟还需要在该项目的 `reBotArm_simulator-RS` 目录执行 `npm install` 和 `npm run prepare:hand`，生成 `public/lib/mediapipe`；这些运行时资源不包含在本仓库中。

页面目标每 0.033 秒读取本项目最新 `logs/servo_*.csv` 的完整诊断行。文件超过 3 秒未更新时显示离线并保持画面。关节数值优先显示有效的 `q_act` 实际反馈，否则显示有效的 `q_cmd` 指令位置并明确标注；当实际反馈与采样时指令均有效时，模型使用实际反馈加后续指令变化作连续估算，并在数据来源中标明“模型估算”。旧日志在待机且没有实际反馈时不会把占位零值显示为指令；这不是高频实测同步。需要运行跟随程序并启用诊断日志；默认 Gemini 336 配置目标 20 Hz 实际反馈；同步读取耗时超过 10 ms 时自动降至 1 Hz，普通配置默认关闭。日志刷新及反馈本身存在延迟。右上角显示控制程序采集的相机彩色预览（目标 10 帧/秒）；夹爪实际反馈目前没有同步。网页服务只监听本机，并通过管理的子进程向现有控制程序发送启停信号；不直接连接 CAN。

Three.js、STLLoader、URDFLoader 来自本机数字孪生项目，遵循它们各自的上游许可证；机械臂和相机资源继续从数字孪生目录读取。

关节列表显示 SDK 原始角度；三维模型应用 `config/joint_offset.json` 的零位修正，与控制器的正运动学一致。缺少或无法读取零位修正时，页面保留模型位置并提示，不假定修正为零。

## 电脑摄像头网页模拟

打开本地页面后选择“电脑摄像头模拟”，点击“开启摄像头”并允许浏览器访问；授权后可在下拉框选择其他摄像头。把手放入画面，左右、上下移动手掌驱动网页模型，拇指与食指捏合控制虚拟夹爪。“重新定位”以当前手掌和模型位置重新建立相对控制；手掌输入与夹爪开度经过自适应平滑和小幅死区处理，减轻静止抖动；手掌丢失时模型保持，重新检测后不会跳到画面中心。关闭摄像头、切换模式或页面进入后台会停止摄像头。

该模式的关节映射仅为二维网页模拟，不进行真实机械臂控制，也不估计手掌深度或进行末端逆运动学。浏览器需支持 WebAssembly、Worker、摄像头和安全上下文；`localhost` / `127.0.0.1` 可用。手势识别在浏览器本机完成，不上传视频。模型使用项目的 `config/hand_landmarker.task`，MediaPipe 浏览器运行资源沿用 `REBOT_TWIN_PATH` 指向的数字孪生项目。

## 网页真机控制

1. 关闭其他占用 CAN 的控制程序，检查供电、CAN、Gemini 336、零位、HOME 和机械臂工作区，并准备急停。此型号的 V1 支架 URDF 是 CAD 名义位姿，尚未完成实机验收。
2. 启动 `python3 web/server.py`，打开本机页面。选择“真机控制”，在相机列表选择 Gemini 336 并点击“打开摄像头”，可在连接机械臂前检查右上角画面。初始化时程序会关闭独立预览并由跟随程序接管同一台相机。首次使用建议保持默认“低速验证”和“夹爪保持当前位置”。
3. 点击“初始化真机”：启动已有 `palm_follow_grasp.py`，使能机械臂并移动到配置的 HOME。HOME 到位检查通过后自动开始跟随；按空格暂停，再按空格恢复，手臂和夹爪保持。仅当选择“捏合控制”时，跟随启用期间才驱动夹爪。
4. 点击“退出并回零”或按 `q` / `Esc`，控制程序将停止跟随、回零并失能。初始化过程中请求退出会等初始化结束后执行，不是紧急停止；紧急情况使用硬件急停。

网页启动使用 J3/J4 HOME 到位容差 3.5°（其余关节保持 2°），不启用重力补偿。网页低速选项只对本次运行临时覆盖 `gain=1.5`、`gain_x=1.5`、末端最大速度 0.10 m/s 和 HOME 速度 4°/s，不修改 YAML。两档均使用 Gemini 336 专用稳定参数；选择“已调整速度”会使用 follow.yaml 中的增益、速度上限和原 HOME 速度。网页只管理自身启动的程序；手动从终端启动仍可使用原本的 `g` / 空格 / `q` / `Esc`。网页控制模式的快捷键由网页处理，避免全局键盘监听重复触发。关闭网页服务时会向其管理的控制程序请求退出。请勿同时使用其他 CAN 控制器；网页可阻止重复启动手掌跟随进程，但无法识别所有可能的 CAN 客户端。

真机六关节位置通过诊断日志更新，实际反馈目标 20 Hz，读取过慢时回退 1 Hz；该数字是目标而非实测速率；反馈失效时标为指令位置。网页右上角在打开独立相机预览后或真机初始化期间显示 Gemini 336 画面；网页目前不显示真机夹爪的实际反馈；虚拟夹爪仅用于电脑摄像头模拟。
