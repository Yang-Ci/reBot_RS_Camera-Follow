# B601 本地监视页面

启动：`python3 web/server.py`，打开 <http://127.0.0.1:8765>。不需要启动机械臂即可查看页面。机械臂 URDF、网格、相机模型和浏览器手部识别资源均包含在项目内；资源来源见 [资源说明](../assets/README.md)。腕部相机与支架的 CAD 名义装配尚未实机验证，见 [模型说明](../models/wrist_camera/README.md)。

电脑摄像头模拟使用项目内的 MediaPipe 网页运行时，无需克隆或安装其他源码仓库。

网页管理的控制程序以目标 20 Hz 向本机网页服务发送状态快照；发送和序列化在后台线程完成，控制线程不会等待网页。网页目标每 0.033 秒读取服务端状态，快照超过 3 秒视为过期。实时通道不可用时回退读取最新 `logs/servo_*.csv`；手动启动的控制程序也可通过日志监视。实时通道不要求开启 CSV 诊断日志。

Gemini 相机预览画面左上角显示同帧深度伪彩色小窗：固定显示 0.15～1.5 米，红色偏近、蓝紫色偏远，黑色表示没有有效深度或超出显示范围。无深度帧或无有效点时显示 `DEPTH NO DATA`。预览不是测距或安全保护装置。

关节数值优先显示新鲜的 `q_act` 实际反馈，否则显示有效的 `q_cmd` 指令位置并明确标注；当实际反馈与采样时指令均有效时，模型使用实际反馈加后续指令变化作连续估算，并在数据来源中标明“模型估算”。旧日志在待机且没有实际反馈时不会把占位零值显示为指令；这不是高频实测同步。跟随控制后台逐关节读取实际反馈，目标 5 Hz，时效及通信负载需实机验证。状态传输及反馈本身存在延迟。 HOME 和回零阶段发布 SDK 下发的关节指令以驱动网页模型，并标记为非实测；实际关节和夹爪运动可能存在误差。右上角显示控制程序采集的相机彩色预览（目标 10 帧/秒）；夹爪实际反馈目前没有同步。网页服务只监听本机，并通过管理的子进程向现有控制程序发送启停信号；不直接连接 CAN。

Three.js、STLLoader、URDFLoader 随项目提供，遵循各自的上游许可证；机械臂和相机资源从项目内读取。

关节列表显示 SDK 原始角度；三维模型应用 `config/joint_offset.json` 的零位修正，与控制器的正运动学一致。缺少或无法读取零位修正时，页面保留模型位置并提示，不假定修正为零。

## 电脑摄像头网页模拟

打开本地页面后选择“电脑摄像头模拟”，点击“开启摄像头”并允许浏览器访问；授权后可在下拉框选择其他摄像头。把手放入画面，左右、上下移动手掌驱动网页模型，拇指与食指捏合控制虚拟夹爪。“重新定位”以当前手掌和模型位置重新建立相对控制；手掌输入与夹爪开度经过自适应平滑和小幅死区处理，减轻静止抖动；手掌丢失时模型保持，重新检测后不会跳到画面中心。关闭摄像头、切换模式或页面进入后台会停止摄像头。

该模式的关节映射仅为二维网页模拟，不进行真实机械臂控制，也不估计手掌深度或进行末端逆运动学。浏览器需支持 WebAssembly、Worker、摄像头和安全上下文；`localhost` / `127.0.0.1` 可用。手势识别在浏览器本机完成，不上传视频。模型使用项目的 `config/hand_landmarker.task`，MediaPipe 浏览器运行资源位于项目内 `web/lib/mediapipe/`。

## 网页真机控制

1. 关闭其他占用 CAN 的控制程序，检查供电、CAN、相机、零位、HOME 和机械臂工作区，并准备急停。相机支架 URDF 是 CAD 名义位姿，尚未完成实机验收。
2. 启动 `python3 web/server.py`，打开本机页面。选择“真机控制”，在相机列表选择实际连接的 Gemini 2、Gemini 305、Gemini 336 或 D435i 并点击“打开摄像头”，可在连接机械臂前检查右上角画面。初始化时程序会关闭独立预览并由跟随程序接管同一台相机。首次使用建议保持默认“低速验证”和“夹爪保持当前位置”。 跟随增益、水平增益和末端速度可在启动前调整；选择档位会重新填入预设，运行中不能修改。每次初始化前需确认 HOME 路径、工作区和硬件急停；该确认不能代替实际检查。网页和服务端均校验增益和速度范围，当前设定只用于本次运行，不写入 YAML。
3. 点击“初始化真机”：启动已有 `palm_follow_grasp.py`，使能机械臂并移动到配置的 HOME。HOME 到位后保持等待；按 R、点击“开始跟随”，或持续张开手掌 3 秒开始。空格只暂停；手掌丢失时使用原跟随处理，反馈或桌面保护锁定暂停后只能人工按 R 或点击恢复，手势不会再次自动启动。仅当选择“捏合控制”时，跟随启用期间才驱动夹爪。
4. 点击“退出并回零”或按 `q` / `Esc`，控制程序将停止跟随、回零并失能。初始化过程中请求退出会等初始化结束后执行，不是紧急停止；紧急情况使用硬件急停。控制器回零或失能接口报错时，程序会记录错误并以非零状态退出，应检查现场设备状态。

网页启动使用 J3/J4 HOME 到位容差 3.5°（其余关节保持 2°），不启用重力补偿。网页低速选项只对本次运行临时覆盖 `gain=1.5`、`gain_x=1.5`、末端最大速度 0.10 m/s 和 HOME 速度 4°/s，不修改 YAML。网页中速验证使用增益 1.9 / 1.9、末端最大速度 0.25 m/s，并保持 HOME 速度 4°/s；这是待实机验证的中间档。Gemini 336 使用专用稳定参数；选择“已调整速度”会使用 follow.yaml 中的增益、速度上限和原 HOME 速度。网页只管理自身启动的程序；手动从终端启动使用 R 开始、g / 空格暂停、q / Esc 请求回零退出。网页控制模式的快捷键由网页处理，避免全局键盘监听重复触发。关闭网页服务时会向其管理的控制程序请求退出。请勿同时使用其他 CAN 控制器；网页可阻止重复启动手掌跟随进程，但无法识别所有可能的 CAN 客户端。

真机六关节位置优先通过本机实时通道更新，实时通道不可用时回退诊断日志；Gemini 336 实际反馈目标为 5 Hz，该数字是目标而非实测速率，反馈失效时标为指令位置。网页在打开独立相机预览后或真机初始化期间显示所选相机画面；真机三维夹爪显示目标指令，不是实际反馈。

### 多人 HOME

“HOME 位姿”可按名称保存多组关节角（单位为度），选择后在下次初始化时使用；待机且无实时反馈时，左侧会显示所选 HOME 的三维预览，预览不会移动机械臂；当前浏览器会记住上次选择。展开“新建或修改 HOME”，检查工作区、回零路径及硬件急停，扶持机械臂后勾选确认并启动重力示教。机械臂完成过渡后可以轻推；停止后等待“已锁定，可保存姿态”，输入名称并点击“保存姿态并回零”。程序验证稳定的实际反馈，发送回零指令并退出后自动保存和选中该 HOME；也可展开手动输入角度。回零指令完成并不代表已确认实际机械臂到达零点。

重力示教与手掌跟随互斥，启停会使能机械臂或执行回零。示教期间不使用关节软限位、零位单向恢复、桌面高度或工作空间边界；请全程扶持，避免碰撞和接近机械限位。示教仍使用实际反馈、URDF 重力与雅可比计算，并保留力矩限制。相机、支架和夹持物会影响负载，模型与实物的误差可能造成下沉或异常运动。反馈超时或力矩异常时程序请求位置保持并显示故障；若无法读到新鲜反馈，不能自动确认安全交接。修改后尚未实机验证。

保存 HOME 不会使能或移动机械臂，后台会按当前 URDF、关节软限位和工作空间验证，启动前也会再次验证；这些检查不验证 HOME 路径或碰撞。个人 HOME 保存在本机 `config/home_profiles/`，不会提交 Git；同名保存会替换该记录，网页会要求确认。默认 HOME 保持在 `config/home_pose.json`。

### 相机位姿与桌面跟随保护

Gemini 2、D435i、Gemini 305 和 Gemini 336 均默认使用对应 URDF 的名义位姿，无需手眼文件。Gemini 2、D435i 和 Gemini 336 使用共用支架的平视版 URDF；D435i 按当前彩色或红外图像选取对应光学坐标。Gemini 2、D435i 和 Gemini 336 共用支架，但相机光心不同；实际安装需与各自 URDF 一致。

桌面端左侧三维视图与相机预览固定在视窗内，右侧控制面板独立滚动。窄屏仍为上下布局。


Gemini 336 跟随处理恢复到添加桌面保护前：短时丢失使用有界外推，较长丢失保持位置，重新识别后沿用原逻辑，不额外要求回到旧位置或固定的恢复速度。深度无效时沿用原深度冻结与超时逻辑；固定夹爪图像屏蔽和后加的深度估算跟随关闭。实际动作可能随重新识别而恢复，请保持工作区畅通。实际反馈缺失、含读取耗时的年龄超过 0.30 秒、或同点关节跟踪误差超过 40° 时暂停。40° 为较大的偏差，不能依靠该阈值及时发现跟踪异常；近限位恢复仍有独立的更严格检查。若反馈读取过慢或通信失败，保护可能拒绝启动；应排查反馈，不应绕过。跟随中以第六关节相对基座坐标高度 0.23 m 为保守阈值，在 0.30 m 以下逐渐限制向下速度；同时使用命令位置和新鲜的实际位置。该阈值基于底座直接放在水平桌面及约 0.174 m 模型包络的临时估算，必须实机核对和留出额外余量。该软件保护不能保证碰撞安全，未覆盖 HOME/回零轨迹、机械臂其他部位、夹持物或硬件通信故障；必须检查现场并准备硬件急停。

Gemini 305 网页可在初始化前选择 30 FPS 稳定采集或 60 FPS 实验采集；实际手掌识别帧率受计算负载影响，可能低于相机输出。彩色曝光设为自动时会主动启用设备的自动曝光。

“静止关节保持”可在网页初始化前开启或关闭，运行时显示当前值并锁定修改；更改在下次初始化生效，不写入配置文件。Gemini 305 和 Gemini 336 默认开启，Gemini 2 和 D435i 默认关闭。它控制手掌静止时的关节指令保持，与桌面和关节反馈保护是独立功能。
